# CyberCore — الأرخص

منصة عربية RTL لمقارنة أسعار قطع الكمبيوتر في العراق بالدينار العراقي.

## النسخة الحالية

الموقع الآن عبارة عن Frontend مستقل يعمل مباشرة من `index.html` بدون Build step، ومصمم ليعمل على GitHub Pages أو أي Static Hosting.

### الصفحات والوظائف
- بحث الكيس التفاعلي: GPU / CPU / Motherboard / RAM / Storage / Cooler / PSU / Case / Fans.
- معلومات توافق لكل مكوّن.
- مقارنة عروض وأسعار وترتيب من الأرخص إلى الأغلى.
- التجميعات الجاهزة مع فلترة حسب الميزانية.
- اللابتوبات مع البحث والترتيب.
- الإكسسوارات مع فلترة حسب النوع.
- المنشورات للمستعمل مع إضافة منشور وحذف المنشورات المحلية.
- آراؤكم مع إضافة رأي وإعجاب وبلاغ.
- حساب مستخدم تجريبي محفوظ في LocalStorage.
- Admin Demo لإدارة العروض والمنشورات والآراء محلياً.
- تصدير نسخة JSON من البيانات المحلية.
- تصميم RTL متجاوب للموبايل والكمبيوتر.
- شريط تنقل مع مؤشر نشط متحرك.
- واجهات Modal وتفاصيل المنتجات والتجميعات.
- هوية CyberCore × الأرخص.

## مهم قبل الإنتاج الحقيقي

النسخة الحالية تعمل فعلياً كواجهة Static، لكن البيانات ليست Live ولا يوجد Backend داخل GitHub Pages وحده.

حتى يصبح المشروع منصة إنتاج كاملة نحتاج لاحقاً:
1. Supabase/Firebase/PostgreSQL.
2. Auth حقيقي: Google / Apple / GitHub + email/password.
3. صلاحيات Admin حقيقية وRLS.
4. جداول المنتجات والمحلات والعروض والتجميعات والمستعمل والتعليقات والبلاغات.
5. مصادر أسعار حقيقية للمحلات أو إدخالها من الإدارة.
6. روابط المنتجات الحقيقية.
7. رفع صور المستخدمين والمنتجات.
8. سجل تغيّر الأسعار ووقت آخر تحديث.
9. نظام مراجعة للبلاغات والمنشورات.
10. حماية بيانات الاتصال بالمستخدمين.

## البيانات التجريبية

أسماء المحلات والأسعار والصور الموجودة داخل الواجهة هي Seed/Demo وليست أسعاراً لحظية أو تفويضاً من أي متجر. يجب دائماً التأكد من السعر والتوفر والضمان من صفحة البائع قبل الشراء.

## ملاحظة

GitHub Pages مناسب جداً للواجهة الحالية، أما قاعدة البيانات والمصادقة ومصادر الأسعار الحية فتحتاج خدمة Backend منفصلة.
