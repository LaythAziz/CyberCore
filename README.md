# CyberCore — الأرخص

منصة عربية RTL لمقارنة أسعار قطع الكمبيوتر في العراق، مبنية داخل هذا المستودع.

## التشغيل
هذا الإصدار Frontend مستقل ولا يحتاج Build step:
- افتح `index.html`
- يعمل على GitHub Pages / Vercel / أي static hosting.

## الموجود حالياً
- بحث الكيس التفاعلي
- مقارنة عروض وأسعار بالدينار العراقي
- التجميعات حسب الميزانية
- اللابتوبات
- الإكسسوارات
- المنشورات (المستعمل)
- آراؤكم
- شرح الموقع والأسئلة الشائعة
- واجهة Admin
- Responsive mobile-first
- هوية CyberCore × الأرخص

## ملاحظة البيانات
البيانات الموجودة حالياً Demo/Seed UI لتجهيز الواجهة. لا تعتبر الأسعار أو التوفر أو روابط المحلات بيانات لحظية أو تفويضاً من المتجر.

## المرحلة التالية للإنتاج الحقيقي
1. ربط قاعدة بيانات مثل Supabase/Firebase/PostgreSQL.
2. Auth حقيقي: Google / Apple / GitHub + email/password.
3. لوحة Admin بصلاحيات حقيقية.
4. مصادر أسعار المحلات (API/feeds أو إدخال من الإدارة).
5. روابط المنتجات الحقيقية.
6. رفع صور المستخدمين والمنشورات.
7. نظام البلاغات والمراجعة.
8. سجل تغيّر الأسعار ووقت آخر تحديث.
